챗봇 최적화 (AutoRAG)

관리자 대시보드
AutoRAG 시스템이란?

AutoRAG는 RAG(Retrieval-Augmented Generation) 챗봇의 모든 구성 요소를 자동으로 최적화하는 시스템입니다. 텍스트 추출, 청킹 전략, 임베딩 모델, 검색 방식 등을 평가하여 최적의 조합을 찾아냅니다.

최적화 단계

1

텍스트 추출

PDF, HWP 파일에서 텍스트를 추출하는 최적의 방법을 선택합니다.

  • PDF: PDFPlumber, PyMuPDF, PyPDF2
  • HWP: olefile, hwp5
실행

2

청킹 전략

문서를 적절한 크기로 분할하는 최적의 전략을 선택합니다.

  • 고정 크기, 재귀 분할, 문장 단위
  • 의미 기반 분할, 슬라이딩 윈도우
실행

3

임베딩 모델

텍스트를 벡터로 변환하는 최적의 임베딩 모델을 선택합니다.

  • OpenAI text-embedding-3-small/large
  • SentenceTransformer 한국어 모델
실행

4

벡터 저장소

선택된 임베딩 모델로 벡터 저장소를 구성합니다.

  • ChromaDB 기반
  • 최적 임베딩 모델 적용
자동 구성

5

검색기 최적화

벡터 검색 방식을 최적화합니다.

  • 유사도 검색, MMR, 하이브리드
  • Top-K 파라미터 최적화
실행

6

RAG 시스템

전체 RAG 시스템을 정교한 메트릭으로 평가합니다.

  • 검색 품질, 답변 품질, 컨텍스트 품질
  • 12가지 평가 지표 적용
실행
전체 파이프라인 자동 최적화

위의 모든 단계를 자동으로 순차 실행하여 최적의 RAG 파이프라인을 구성합니다. 각 단계의 최적 설정을 찾고, 최종적으로 챗봇 시스템의 성능을 종합 평가합니다.

* 전체 최적화는 5~10분 정도 소요될 수 있습니다.
